5. 통관·규제 (리쉬·하네스·칼라 기준)

  • HS코드 1순위: 4201.00 (동물용 마구류 — 목줄·리드·하네스 명시 포함, 재질 불문)
  • 기본 관세 8% + 부가세 10%. 한중FTA 협정세율 0~0.8% 추정 (⚠️ 스니펫 상충 — 유니패스/관세사 최종 확인 요). FTA 적용엔 원산지증명서(C/O) 필요, 단 물품가 USD 700 이하는 C/O 면제 → 샘플 단계에 유용
  • KC 인증: 법정 대상 아님 (전기·어린이제품 아님). 동물검역도 비대상 (가죽 부자재 쓰면 별도 확인)
  • 2026년 4월 리드줄·목줄·하네스 단체표준 최초 제정 (SPS G KOTITI-7698:2026, 자율) — "시중 절반 기준 미달" 보도와 함께 등장. 시험성적서 취득 시 소자본 브랜드의 강력한 차별화 무기
  • 원산지표시 의무: "Made in China" 라벨 견고 부착 필수 — 공장에 사전 요청
  • ⚠️ 심화 필요: 금속 부자재(D링 도금) 안전기준준수 품목 해당 여부

7. 소자본 첫 수입 4단계 플로우 (지영 추천)

0단계 — 스펙 확정 (0원, 1주): 웨빙 폭(15/20/25mm)·버클·D링·사이즈·컬러 문서화. 도매꾹 범용품 1~2개로 기준점. 1688 후보 공장 3~5곳 스크리닝

1단계 — 샘플 확보 (10~20만원, 2주): 구매대행으로 3~5개 공장 × 2~3종 재고 샘플 → 항공 배대지. USD 700 이하라 C/O 없이 통관 부담 최소

2단계 — 소량 테스트 사입 (50~150만원, 3~4주): 1~2개 공장 재고품 100~300개, 해운 배대지 + 정식통관 1회 경험. 스마트스토어 실판매 반응 측정

3단계 — 본 발주 OEM (300만원~, 6~8주): 알리바바 RFQ로 견적 교차검증 → 1688 공장 커스텀 발주(SKU당 300~500개). C/O 발급 계약 명시 + KOTITI 시험성적서 취득. 해운 LCL + 대행 검품 필수
